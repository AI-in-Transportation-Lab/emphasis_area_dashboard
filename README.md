# Emphasis Area Dashboard

Interactive dashboard of Texas crashes (2020–2025) by Strategic Highway Safety Plan Emphasis Area, built from TxDOT CRIS crash records (about 3.7 million crashes).

**Live site:** https://ai-in-transportation-lab.github.io/emphasis_area_dashboard/

## What it shows

- **Dashboard:** filter by Emphasis Area, year and severity (all crashes or fatal + serious) to see a map of K/A crashes, yearly trends, roadway and environmental conditions, driver details, ADAS vehicle technology and top contributing factors.
- **Group-wise Analysis:** combine Emphasis Areas and compare their overlap.
- **Glossary:** definitions of Emphasis Areas, KABCO severity, ADAS groups and the CRIS variables used.

## Running it

The whole dashboard is one self-contained file, `index.html`, with the data built in. Open it in a browser, or use the live site. The map's base layers need an internet connection.
